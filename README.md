# השוואת עסקאות נדל"ן לפי אזור

מפה שבה מסמנים אזורים ומשווים ביניהם את עסקאות המקרקעין: ממוצע וחציון של מחיר למ"ר לפי קבוצות גודל וגיל בניין, אחרי סינון חריגים; שינוי בין שתי שנים; מגמה שנתית; איכות הנתונים; ותחלופה ביחס למשקי הבית. כל מספר מוצג יחד עם העסקאות, השאילתה והנוסחה שהפיקו אותו.

## מקורות

- **[גרסאות לעם (OVER)](https://www.over.org.il)**, דרך ממשק ה-SQL הציבורי שלו, לקריאה בלבד:
  - מאגר עסקאות המקרקעין של רשות המסים (כ-3.8 מיליון עסקאות מ-1998);
  - שכבת החלקות;
  - שכבת השכונות של המרכז למיפוי ישראל;
  - שכבת האזורים הסטטיסטיים 2022 של הלמ"ס עם נתוני מפקד 2022.

  השורות מוצגות כפי שפורסמו, בלי תיקון.
- **מקור חוץ: טבלאות עזר ממשתמש האתר**, שנשמרות רק בפרויקט הזה ([data/external](data/external/README.md)): סיווג מהות עסקה לסוג נכס (קטגוריות מפ"י), גוש לשכונה, ומאפייני יישובים של הלמ"ס. הן רשומות ב-[`sources.json`](data/external/sources.json) כמקור מסוג `external`, לצד OVER.

## מה יש במסך

- **מפה** עם שכבת גוש/חלקה (מזום 16), מפת רחובות או תצלום אוויר, וחיפוש לפי `6953/31`, `גוש 6953` או כתובת.
- **שכבות נתונים מ-OVER** (בפינת המפה, מתחת לבורר המפה):
  - גבולות השכונות (מפ"י) והאזורים הסטטיסטיים 2022;
  - מפה נושאית לפי אזור סטטיסטי: מדד חברתי-כלכלי 2021, אוכלוסייה 2024, צפיפות, משקי בית, גיל חציוני, שיעור בעלות על דירה, שיעור אקדמאים ושכר חציוני (מפקד 2022). לכל מפה יש מקרא.
- **אזורים:**
  - ציור במברשת בעובי נבחר, ומחק;
  - **בחירת שכונות** (שכבת מפ"י) או **אזורים סטטיסטיים** (למ"ס 2022) בלחיצה על הפוליגונים במפה. כברירת מחדל כל לחיצה מצרפת את הפוליגון לאזור הפעיל, כך שכמה שכונות או אזורים סטטיסטיים נבחנים כאזור אחד (לחיצה חוזרת מוציאה). אפשר גם לבחור שכל לחיצה תיצור אזור חדש.

  אפשר כמה אזורים, והם יכולים לחפוף, להיות מוכלים או נפרדים.
- **סינון:**
  - סוג נכס (ברירת מחדל: מגורים רווי; "לא רלבנטי" ו"סחר נדל"ן" מחוץ לניתוח המגורים);
  - טווח שנים ושנות השוואה;
  - קבוצת גודל וגיל הבניין;
  - שיטת סינון החריגים;
  - המדד: ממוצע או חציון, של מחיר למ"ר או של שווי עסקה.
- **תוצאות בחמש לשוניות:**
  - **השוואה:** גרף לאורך הזמן וטבלה;
  - **פילוח:** מגמה ו-R² לכל קבוצת גודל ולכל קבוצת גיל;
  - **גרפים:** רמה, מדד 100, ועסקאות בשימוש מול שסוננו;
  - **חומר גלם:** סיכום שנתי, מה סינון החריגים עשה בכל תא, יישובים, וכל העסקאות עם הורדה ל-CSV;
  - **נוסחאות ושיטה:** כולל הצבת המספרים של כל אזור.

## איך זה מחושב

1. **מאזור לעסקאות.** המאגר אינו כולל קואורדינטות, ולכן נכללת כל חלקה שנקודה פנימית שלה בתוך האזור, והעסקאות מחוברות לחלקות לפי גוש + חלקה. OVER מחזיר את העסקאות עצמן כשורה אחת בפורמט JSON, וכל השאר מחושב בדפדפן.
2. **עסקה תקינה ומחיר למ"ר.** עסקה תקינה היא עם שווי ≥ 10, שטח > 0 וחלק נמכר > 0. המחיר: `P = שווי / (שטח × חלק נמכר)`.
3. **קבוצות גודל:** ללא גודל, 2–54, 55–80, 81–104, 105–140, 141+ מ"ר. אלה הגבולות שה-VLOOKUP בקובץ העזר מפעיל בפועל. "ללא גודל" לא נכנס לחישוב מחיר.
4. **סינון חריגים בכל תא (אזור × גודל × שנה), על ln המחיר:**
   - קודם ניקוי גס: חציון ± 4 סטיות תקן חסינות (MAD);
   - אחר כך שני סבבים של ממוצע ± 2 סטיות תקן;
   - בתא קטן הגבולות מחושבים על קבוצת ייחוס מורחבת של לפחות 20 עסקאות.

   חלופה: טווח קבוע של 1,000–80,000 ₪ למ"ר.
5. **סטטיסטיקה שנתית:** ממוצע, חציון, סטיית תקן ו-n. שנה נכנסת לנוסחאות רק מעל מינימום עסקאות.
6. **שינוי:**
   - `Δ% = (M_B / M_A − 1) × 100`;
   - `CAGR = ((M_B / M_A)^(1/(B−A)) − 1) × 100`.
7. **מגמה:** רגרסיה משוקללת (משקל = n_t) של `ln M_t` על השנה. `T = (e^b − 1) × 100`, עם R².
8. **גיל הבניין:** `שנת עסקה − שנת בנייה`, בקבוצות. שנת בנייה לא סבירה נחשבת "לא ידוע".
9. **איכות הנתונים:** חלק העסקאות שנכנסו לחישוב. אזור שבו פחות מחצי מהעסקאות בשימוש מסומן ⚠ ובקו מקווקו.
10. **תחלופה:** עסקאות לשנה ל-1,000 משקי בית. משקי הבית נלקחים ממפקד 2022, לפי החלק של כל אזור סטטיסטי שבתוך האזור. זה קירוב למלאי הדירות המאוכלסות.

המימוש: [`js/analysis.js`](js/analysis.js) ו-[`js/stats.js`](js/stats.js), עם בדיקות ב-[`tests/`](tests).

## הרצה מקומית

אתר סטטי בלי שלב בנייה. Leaflet, Turf ו-Chart.js נטענים מ-jsDelivr עם SRI.

```bash
npm run serve   # http://localhost:5190
npm test
npm run stamp   # לפני כל פרסום: חותמת גרסה על כתובות הקבצים, כדי שדפדפנים לא יריצו קוד ישן
```

## מגבלות

- OVER מגביל 20 שאילתות SQL בדקה לכל כתובת IP, ולשאילתה יש תקרת זמן של כ-10 שניות.
- אזור עם יותר מ-150,000 עסקאות נדחה.
- המאגר אינו מפרסם תת-גוש.
- משקי בית אינם מלאי יחידות דיור.
- ממוצע שנתי משקף גם את תמהיל הנכסים שנמכרו.
