# השוואת עסקאות נדל"ן לפי אזור

מפה שבה מסמנים אזורים במברשת ומשווים ביניהם את עסקאות המקרקעין: חציון מחיר למ"ר (מנורמל לחלק הנמכר), שינוי בין שתי שנים, שינוי שנתי ממוצע ומגמה לאורך השנים. כל מספר מוצג יחד עם חומר הגלם, השאילתה והנוסחה שהפיקו אותו.

**מקור הנתונים היחיד:** [גרסאות לעם (OVER)](https://www.over.org.il/projects/deals) — מאגר עסקאות המקרקעין של רשות המסים (כ-3.8 מיליון עסקאות מ-1998) ושכבת החלקות (גוש/חלקה). השורות מוצגות כפי שפורסמו, בלי תיקון או השלמה.

## מה יש במסך

- **מפה** עם שכבת גוש/חלקה (מזום 16; מספרי חלקות מזום 18), מפת רחובות או תצלום אוויר.
- **חיפוש**: `6953/31` (גוש/חלקה), `גוש 6953`, או כתובת/מקום חופשי (OpenStreetMap Nominatim).
- **מברשת** בעובי נבחר במטרים (5 מ' עד 2 ק"מ), **מחק**, וכמה **אזורים** — חופפים, מוכלים או נפרדים.
- **סינון**: מהות העסקה (ברירת מחדל: דירה בבית קומות), טווח שנים, שנות ההשוואה, מינימום עסקאות לשנה, והמדד.
- **תוצאות** בארבע לשוניות: השוואה, גרפים, חומר גלם (סיכום שנתי + העסקאות עצמן, עם הורדה ל-CSV ואת ה-SQL), נוסחאות ושיטה (כולל הצבת המספרים של כל אזור).

## איך אזור הופך לעסקאות

המאגר של רשות המסים אינו כולל קואורדינטות, רק גוש וחלקה. לכן:

1. משיכת מברשת = קו מורחב (buffer) בחצי מעובי המברשת; האזור = איחוד המשיכות פחות משיכות המחק.
2. נכללת כל חלקה שנקודה פנימית שלה (`ST_PointOnSurface`) בתוך האזור.
3. העסקאות מחוברות לחלקות לפי גוש + חלקה, ומסוננות לפי מהות ושנה.

החישוב כולו רץ ב-OVER, בשאילתת SQL ציבורית לקריאה בלבד (`POST /api/append/{dataset}/sql`), והדפדפן מקבל שורה אחת לכל שנה.

## הנוסחאות

- מחיר למ"ר מנורמל: `P = deal_amount / (asset_area × portion)`; לכל שנה `M_t = median(P)`.
- שנה נכנסת לחישוב רק אם `n_t ≥` המינימום שנבחר.
- שינוי: `Δ% = (M_B / M_A − 1) × 100`, `CAGR = ((M_B / M_A)^(1/(B−A)) − 1) × 100`.
- מגמה: רגרסיה משוקללת (משקל = n_t) של `ln M_t` על השנה, `T = (e^b − 1) × 100`, עם R².
- בין אזורים: `L = 100 × M_B(area) / M_B(ref)`, `G = T(area) − T(ref)`, ומדד `I_t = 100 × M_t / M_A`.

המימוש: [`js/stats.js`](js/stats.js), עם בדיקות ב-[`tests/stats.test.mjs`](tests/stats.test.mjs).

## מגבלות

- OVER מגביל 20 שאילתות SQL ו-30 בקשות חלקות בדקה לכל כתובת IP, ו-1,000 שורות לשאילתה (העסקאות נטענות בדפים).
- לשאילתה יש תקרת זמן של כ-10 שניות; אזור בגודל עיר שלמה עלול לחרוג ממנה.
- המאגר אינו מפרסם תת-גוש; חלקות עם אותו גוש+חלקה ותת-גוש שונה עלולות לחלוק עסקאות.
- חציון שנתי משקף גם את תמהיל הנכסים שנמכרו, לא רק שינוי מחיר.
